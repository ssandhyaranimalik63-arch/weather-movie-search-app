Weather and Movie Search App

About the Project

This is a beginner-friendly web development project that contains two applications:

1. Weather App
2. Movie Search App

Features

Weather App

- Search weather by city name.
- Displays temperature.
- Shows humidity.
- Shows wind speed.

Movie Search App

- Search movies by title.
- Displays movie poster.
- Shows release date.
- Displays IMDb rating.
- Shows movie plot.

Technologies Used

- HTML
- CSS
- JavaScript
- Open-Meteo Weather API
- OMDb Movie API

Project Files

- index.html
- weather.html
- movie.html
- style.css
- api.js
- weather.js
- movie.js

How to Run

1. Download or clone the project.
2. Open the project folder in VS Code.
3. Open index.html in a browser.
4. Select Weather App or Movie Search App.
